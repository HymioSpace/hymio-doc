# Hymio

Hymio 是基于 Oath 的个人助手应用，提供客户端、账号、持续对话、任务、附件和执行设备接入。

这里先解释常见概念，再按目标进入使用与开发文档。如果要把 Oath 接进其他产品，请阅读 [Oath 文档](../oath/)。

## 先看整体结构

<ProjectOverviewMap kind="hymio" />

你通过客户端发出请求，Hymio 校验账号与权限，Oath 推进 Agent 的执行。关闭客户端后，已接纳的工作仍可在服务端继续。Nostalgia 是设计中的上下文组件，尚未接入这条链路。

## 先认识这些术语

| 术语 | 在这里是什么意思 |
| --- | --- |
| Agent | 由 AI 模型驱动、可以调用工具完成工作的助手。 |
| Client / 客户端 | 你使用的 Web、桌面或 iOS 界面，负责输入、展示和接收进展。 |
| Backend / 后端 | Hymio 的服务端，管理账号、权限和产品数据，并把消息转交给 Oath。 |
| Oath / Harness | 让 Agent 运行的执行框架，连接模型与工具、保存执行进度；[先读 Oath 概览](../oath/)。 |
| Task / 任务 | 想达成的目标与完成条件，例如“每周回顾待办”。 |
| Run / 执行尝试 | 任务的一次执行。周期任务会有多次 Run，某次完成不等于取消整个计划。 |
| 附件 | 上传到账号下、可供 Agent 读取的文件；可从 Web / Desktop 或原生 iOS 的附件入口提供。 |
| 执行设备 / 云电脑 | Agent 使用的远程工作环境，不是正在看对话的手机或电脑。 |
| Provider / 供应商 | 提供模型或云电脑的外部服务，需由部署者配置凭据。 |
| 管理平台 | 管理员为用户开通资源、查看容量和管理设备的独立界面。 |
| Hymio UI / A2UI | 让助手回复包含卡片、选项和表单的受限 UI 协议；[查看交互示例](./ui#先试一个例子)。 |
| Kit | 计划中的应用能力模块，当前尚未集成。 |
| ACK / Cursor / Trace | 分别表示“输入已接纳”、客户端收到的事件位置，以及检查执行过程的技术记录；ACK 不代表任务已完成。 |

## 产品边界

Hymio 负责身份、授权、任务状态、上传和设备分配；Oath 负责 Agent 执行与事件投递。Nostalgia 是独立的个人上下文设计项目，目前尚未接入。

Web 与 Tauri 共用 React 前端；iOS 是原生 SwiftUI 客户端，使用相同后端和事件契约。管理平台是独立的 `/admin/` 应用。Chrome 扩展已有结构，但尚不具备主客户端的完整能力。

## 当前限制

项目仍处于持续演进的 MVP 阶段。云设备需要管理员授权；用户 Mac 原生控制与云手机尚未开放，Kit 和 Nostalgia 集成属于后续工作。
